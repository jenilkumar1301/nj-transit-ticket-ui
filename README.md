# Transit Ticket UI

A frontend-only React project that demonstrates a mobile bus-ticket purchase and activation flow inspired by public-transit applications.

## Important

This is an educational interface demo. It is not affiliated with NJ TRANSIT, does not sell fares, and cannot be used for travel. Every active ticket is permanently marked **DEMO — NOT VALID FOR TRAVEL**. It contains no scannable barcode or official validation mechanism.

## Planned flow

1. Select a sample bus route and fare type.
2. Add a ticket to the local wallet.
3. Review the activation warning.
4. Activate the ticket.
5. Watch the expiration countdown and animated validation-style background.
6. View the expired state.

All data stays in the browser. There is no backend, account system, or payment processing.
